# noor-player

Review-playeren fra Noor OS som statisk webside (GitHub Pages), så videoer i Dropbox kan ses i playeren fra enhver browser — også arbejds-pc'en.

- Kilden er `Universal Player.html` i vaulten (Noor OS); denne `index.html` er en kopi, som robotten pusher ved ændringer. Redigér aldrig her.
- Siden indeholder ingen links, data eller nøgler. Videoer, transkripter og noter hentes gennem Bogreolen (sky-artefakt) via `postMessage`, når playeren åbnes derfra.
